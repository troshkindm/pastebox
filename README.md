# PasteBox

Учебный проект: веб-приложение для хранения текстовых фрагментов по уникальной ссылке.

Стек: Go 1.27.1, chi 5.3.1, pgx 5.11.0, PostgreSQL 18.6, Docker Compose.

## Запуск

```sh
cp .env.example .env
docker compose up -d --build
```

Приложение: http://localhost:8080

## Маршруты

- `GET /` — форма ввода;
- `POST /paste` — сохранить текст, редирект на `/p/{id}`;
- `GET /p/{id}` — показать сохранённый текст (404, если записи нет).
